# Code of Conduct

## Our Pledge
We pledge to make participation in **NEXUS System Optimizer** a respectful, harassment-free, and collaborative experience for everyone, regardless of background or experience level.

## Expected Behavior
- Be respectful, constructive, and empathetic in issues, discussions, and pull request reviews.
- Focus feedback on code quality, system safety, and user value.
- Follow the project's safety-first Windows engineering principles.

## Unacceptable Behavior
- Harassment, insults, trolling, or personal attacks.
- Submitting malicious code, backdoors, or unsafe OS modifications.
- Bypassing review rules or publishing private user data.

## Enforcement
Project maintainers (`@digitcodestudio`) have the right to remove, edit, or reject comments, commits, issues, and pull requests that violate this Code of Conduct.
